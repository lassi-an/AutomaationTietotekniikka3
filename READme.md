# AutomaationTietotekniikka3

**Projekti:** Frisbeegolf-säävahti

**Projektin idea:**

Projektin tarkoituksena on tehdä sovellus, joka kertoo, millaiset sääolosuhteet sopivat frisbeegolfin pelaamiseen. Sovellus näyttää ajankohtaiset säätiedot ja arvioi niiden perusteella, kannattaako pelaamaan lähteä.

**Projektikuvaus:** Projektin tarkempi kuvaus löytyy projektin dokumentaatiosta.

**Linkki sovellukseen:**  
[Frisbeegolf-säävahti](https://fribeegolfsaavahti.streamlit.app/)

**Huomio sovelluksen avaamisesta:**

Sovelluksen ensimmäisessä avaamisessa saattaa joutua odottamaan hetken. Streamlit voi sulkea käyttämättömän sovelluksen automaattisesti, mutta se käynnistyy uudelleen, kun linkki avataan. Sovelluksen pitäisi tämän jälkeen toimia normaalisti.
